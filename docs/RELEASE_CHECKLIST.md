# 维护者发布检查

当前建议标签：`v0.5.1-beta.1`，勾选 GitHub **Set as a pre-release**。不要称作长期稳定版本。

## 离线与打包

- 源码中不包含固定的开发者工具路径、账号、令牌或本机日志。
- 执行完整构建，确认四个组件都来自当前源码，作者元数据为“樊小胃”。
- 执行打包与 `tests/Test-Release.ps1`，核对 ZIP 顶层可直接解压到游戏根目录。
- 包内仅本项目二进制，不包含游戏、Steam、Euterpe、MelonLoader DLL。
- 包内不含真实配置、state、转储或调试探针；没有会覆盖其他模组的通用根目录 README。
- SHA256 清单与 ZIP 校验文件存在，设置默认值和已有设置保留行为正确。
- 停用／恢复两插件测试通过，原有游戏、Euterpe 和其他文件保留。
- README 明确免费开源、欢迎贡献和长文字限制。
- 运行完整构建中的实际 Hub 主 DLL 探针：只安装主 DLL 后能准备全部文件，清单一致、个人配置保留、再次准备不重写；旧控制器桩可优雅退出更新。
- 执行 `scripts/package-hub.ps1`，上传的文件有嵌入资源，MelonInfo 名称、作者、版本与表单严格一致，不能拿旧版裸主 DLL 上传。

## 实机回归（尚待完成）

- 重开游戏，核对加载阶段非打歌状态。
- 本体开曲 → 结算 → 选歌。
- Euterpe 开曲，曲名与歌曲作者均正确。
- 暂停／恢复、重开同曲、长文字后返回菜单、退出游戏。
- 游戏过程中修改设置，好友视角核对；好友聊天保持连接。
- 检查是否出现新的 Steam 崩溃转储，核对重复通知行为。
- Hub 新装：只放主 DLL，正常启动一次，默认显示和独立设置入口都可用；再次启动核对早期状态。
- Hub 升级、停用、卸载以及设置窗口仍打开时的受控失败提示，均需实机核对。

发布时如仍未完成这些项目，必须在 Release notes 中保留“实机回归待完成”，不能把离线通过写成实机通过。
