默认显示
不打歌时：Muse Dash
打歌时：Muse Dash : 曲名
非打歌自定义文字、作者默认关闭，可随时自行开启。
升级保留已有设置；要使用新默认值，点“恢复默认”再保存。

先确认：是否已经为 Muse Dash 安装 MelonLoader？

从 Euterpe Hub 下载本插件的玩家
点击下载后照常启动游戏即可，单个 DLL 会自动准备配套文件。
第一次运行后，双击游戏根目录 MuseDash-Settings.cmd 自定义显示。
无需额外下载软件，也不需要让其他管理器保持开启。
不改设置时可直接使用默认显示；以后改设置不需要先开游戏。

一、已安装 MelonLoader 0.7.3 net6，游戏能正常进入
1. 退出游戏和本软件设置窗口。
2. 将玩家下载包的全部内容解压到游戏根目录，与 musedash.exe 同级。
3. 双击 MuseDash-Settings.cmd，修改内容，点击“保存并应用”。
4. 再从 Steam 启动游戏，插件读取已保存的设置。

二、没有加载器，或只下载过安装器但没安装
1. 从官方页面下载 Windows 的 MelonLoader.Installer.exe：
   https://github.com/LavaGang/MelonLoader.Installer/releases/latest
2. 关闭游戏，打开安装器，选择 Muse Dash。
   找不到时点击 Add Game Manually，选择游戏的 musedash.exe。
3. 选择加载器版本 0.7.3，点击 Install。
4. 启动游戏一次完成加载器初始化，确认能进入游戏后退出。
5. 再按“一”中的步骤解压本插件、设置、开始游戏。

也可通过 Euterpe 的首次环境配置流程安装加载器。
官方页面：https://github.com/Euterpe-org/App/releases/latest
完成向导后会自动下载并安装 MelonLoader；只下载 Euterpe 不算安装。
向导也会准备运行库、基础模组及处理冲突，需满足 Euterpe 自身条件。
已有加载器的玩家无需为了本插件重跑整个向导。

独立操作
设置软件不要求启动游戏或 Steam，也不需要打开其他模组管理器。
先保存、再开游戏即可。游戏中也能改显示，保存后约 1 秒更新。
先退出游戏，再用本窗口“启用插件／停用插件”同时控制两个组件。
关闭窗口只是关闭设置编辑，不等于停用插件。

会打扰好友吗？
当前已验证客户端下，选歌、开曲、返回选歌只更新状态，
不会反复触发“开始玩游戏”的新弹窗，不用担心打扰好朋友们～
首次启动游戏仍可能正常通知；未来 Steam 客户端行为变化需重新验证。

Steam 要求
建议保持最新正式版。2026-11-01 已核对客户端构建 1792618285。
未来更新后仍以软件兼容检查为准，版本未适配时不会发送状态。

已知限制
同时显示曲名和作者时，可能因长度或界面限制而显示不全。
目前没有保证完整显示的解决方案；可关闭作者或缩短分隔符。
